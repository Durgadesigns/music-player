# Tempo

A two-screen music player concept (Home and Now Playing), inspired by popular streaming apps. Unofficial design concept, not affiliated with any music service.

Built with React + Vite. No backend, no API keys: songs are mock data, and the album covers in `public/covers` are original generative artwork.

```bash
npm install
npm run dev
```

Design tokens (colors, radius, spacing, type) live in `src/tokens.css`.
